# Pharmtech Web Application – Project Documentation (Cursor/Antigravity Ready)

## 1) Project Overview
Build a modern business web application for **Pharmtech** (CCTV, Solar, Networking, Starlink, Automation, Access Control).

The app has:
- A **public homepage** showing product categories, featured products (with images), and key business actions (Get a Quote, Solar Calculator, WhatsApp, Contact).
- A **Products** section with categories:
  - CCTV
  - Solar
  - Networking
  - Automation
  - Access Control
- A **Customer Dashboard** (Sign up / Sign in) where customers can:
  - View their profile
  - See their points
  - View referrals
  - View orders/requests
- A **Rewards system**:
  - Customers earn points when they patronize (purchase/request)
  - Customers earn points when they refer others who patronize
  - Points can later be used to buy products (redemption workflow)

We will use **Supabase** for:
- Database (Postgres)
- Authentication
- Storage (product images and homepage assets)

## 6) Database Schema (Supabase Postgres)

### Tables

#### 6.1 profiles
- id (uuid, pk, references auth.users)
- full_name (text)
- phone (text)
- address (text)
- role (text) default 'customer'  // 'customer' or 'admin'
- points_balance (int) default 0
- created_at (timestamp)

#### 6.2 product_categories
- id (uuid, pk)
- slug (text, unique)  // cctv, solar, networking, automation, access-control
- name (text)
- description (text, nullable)
- image_url (text, nullable)
- created_at (timestamp)

Seed categories:
- CCTV
- Solar
- Networking
- Automation
- Access Control

#### 6.3 products
- id (uuid, pk)
- category_id (uuid, references product_categories.id)
- name (text)
- description (text)
- price (int, nullable)
- image_url (text)          // Supabase storage public URL
- is_featured (bool) default false
- is_active (bool) default true
- created_at (timestamp)

#### 6.4 orders (or requests)
- id (uuid, pk)
- user_id (uuid, references profiles.id)
- status (text) default 'pending' // pending, confirmed, completed, cancelled
- total_amount (int, nullable)
- created_at (timestamp)

#### 6.5 order_items
- id (uuid, pk)
- order_id (uuid, references orders.id)
- product_id (uuid, references products.id)
- qty (int)
- unit_price (int, nullable)

#### 6.6 referrals
- id (uuid, pk)
- referrer_user_id (uuid, references profiles.id)
- referred_user_id (uuid, references profiles.id)
- referral_code (text)
- status (text) default 'signed_up' // signed_up, first_purchase_completed
- created_at (timestamp)

#### 6.7 points_transactions
- id (uuid, pk)
- user_id (uuid, references profiles.id)
- type (text)  // earn_purchase, earn_referral, redeem
- points (int) // positive for earn, negative for redeem
- reference (text) // order_id or referral_id
- created_at (timestamp)

### Rewards Rules (initial)
- On completed purchase: +X points based on amount OR fixed
- On referral first purchase completed: referrer +Y points
- Points redemption: subtract points and create record

Rules should be configurable later (admin UI optional).
